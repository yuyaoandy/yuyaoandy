### 容斥

有若干个集合 $S_1,\cdots,S_n$，如果能够算出一些集合交集的大小，那么就可以求出它们并集的大小。

设 $A=\{x|x\le n,x\in N^*\}$

$|\bigcup_\limits{i=1}^n S_i|=\sum_\limits{T \neq \varnothing,T\subseteq A} (-1)^{|T|-1}|\bigcap_\limits{i\in T} S_i|$

发现这样每个集合中的元素恰好被统计了一次。

举一个简单的例子：

$n=3$，$S_1=\{1,2,3,5\},S_2=\{2,3,4\},S_3=\{3,4,5\}$。

很显然 $|\bigcup_\limits{i=1}^n S_i|=5$

但是如果直接 $|S_1|+|S_2|+|S_3|$ 算出来的就是 $10$。

发现问题处在有些元素在多个集合中出现了，需要减去。

比如 $2$ 就在 $S_1$,$S_2$ 中都出现了。

枚举两个集合，那么这些在多个集合中出现的就是这两个集合的交集。

但是 $|S_1|+|S_2|+|S_3| - |S_1 \bigcap S_2| -|S_2\bigcap S_3| - |S_3\bigcap S_1|=4$。

因为元素 $3$ 在 $S_1\bigcap S_2 \bigcap S_3$ 中出现了，而在上面减去的过程中减去了 $3$ 次，多减去了，需要加上 $|S_1\bigcap S_2 \bigcap S_3|$。

于是最终答案为 $|S_1|+|S_2|+|S_3| - |S_1 \bigcap S_2| -|S_2\bigcap S_3| - |S_3\bigcap S_1| + |S_1\bigcap S_2 \bigcap S_3|=5$。

然后拓展到一般的情况就有上面这个公式了。

简单应用：

T1

错排问题：问长为 $n$，满足 $\forall p_i\neq i$ 的排列数量。

考虑有至少几个 $p_i=i$，钦定这些数的位置，剩下的数任意排列，由于这只和选出的集合数量有关。

设至少有 $x$ 个位置满足，则答案显然为 $\binom{n}{x}(n-x)!$。

枚举 $x$，答案为 $\sum_\limits{x=0}^n(-1)^x \binom{n}{x}(n-x)!$

可以得到 $f_n=f_{n-1}+(-1)^n$。

#### 例题 1.1

[[COCI2009-2010#6] XOR](https://www.luogu.com.cn/problem/P4515)

有一个 $O(2^n)$ 的简单做法，就是枚举子集容斥，一些子集的异或面积是容易计算的。

然后套用上面的公式即可。

但是有更加优秀的做法。

考虑枚举平面中三角形的三条边是由原来的哪几个三角形的三条边组成的。

显然，这样时间复杂度是 $O(n^3)$ 的。

这样只需要计算这个三角形容斥系数和即可。

直接计算仍然较难，考虑转化为包含这个三角形的所有三角形容斥系数和。

设包含 $T$ 的三角形有 $m$ 个，则系数和为 $\sum_{i=1}^m\binom{m}{i}\times 2^{(i-1)}=\frac{(-1)^m-1}{-2}$

即当  $m$ 为偶数时为 $0$ 否则为 $1$。

然后通过三维差分即可计算。

#### 例题 1.2

[[ARC101E] Ribbons on Tree](https://www.luogu.com.cn/problem/AT_arc101_c)

考虑容斥，如果这些路径没有覆盖所有的边，那么这棵树就会被分成一个一个连通块。

设断掉的边的集合是 $S$,则最终的答案是 $\sum(-1)^{|S|}P(S)$，其中 $P(S)$ 表示钦定断这些边，让块内自己匹配自己的方案数（块内仍然可能不连通）。

考虑 DP，$F_{i,j}$ 表示 $i$ 子树内有 $j$ 个节点和 $i$ 在同一连通块的方案数。

可以通过树上背包进行转移，唯一的问题就是计算一个子树内恰好两两配对的方案数。

设 $T_i$ 为连通块中有 $i$ 个节点，两两配对的方案数，当 $2|i$ 时， $T_i=\prod _ {i=1}^{\frac{i}{2}}(2i-1)$

做树上背包时可以钦定一个点到儿子的边断或者不断，统计方案。

```cpp
inline void dfs(int x,int fa) {
	F[x][1]=1;
	sz[x]=1;
	for(int i:vec[x])
		if(i!=fa) {
			dfs(i,x);
			for(int j=sz[x]; j; --j) {
				int s=F[x][j];
				F[x][j]=0;
				for(int k=sz[i]; ~k; --k)
					F[x][j+k]=(F[x][j+k]+1ll*s*F[i][k])%md;
			}
			sz[x]+=sz[i];
		}
	for(int i=2; i<=sz[x]; i+=2)
		add(F[x][0]=(F[x][0]-1ll*F[x][i]*T[i])%md+md);
}// F[x][0] 表示的是 i 子树内恰好匹配的方案数,F[x][j] 有 j 个点连通（都带着容斥系数的）
```

### 二项式反演

二项式反演本质上也是一类容斥，是用于解决这类问题的：

有 $n$ 个集合，问其中恰好属于 $k$ 个集合的元素数量。

设答案为 $ans_k$，先求出一个 $f_k$ 表示至少属于 $k$ 个**钦定**集合的元素数量（也就是说这一个元素可能出现在其他集合里，只是我没有**钦定**它出现）。

枚举每个元素实际属于几个集合可以得到 $ans_i=\sum_{j=i}^n(-1)^{j-i}\binom{j}{i}f_j$。

（因为如果一个元素实际出现在 $k$ 个集合里，那么选择 $j$ 个集合使得这个元素出现在这 $j$ 个集合中有 $\binom{k}{j}$ 的方案数，也就是说会对 $f_j$ 造成 $\binom{k}{j}$ 的贡献）

得到 $f_i=\sum_{j=i}^n\binom{j}{i}ans_j$，容斥一下就可以得到 $ans_i=\sum_{j=i}^n(-1)^{j-i}\binom{j}{i}f_j$。

当然，二项式反演还有另外一形式： $f_i=\sum_{j=0}^i \binom{i}{j} g_j \leftrightarrow g_i=\sum_{j=0}^i (-1)^{i-j} \binom{i}{j} f_j$。

推一下式子 $f_i=\sum_{j=0}^n \binom{i}{j} \sum_{k=0}^j (-1)^{j-k} \binom{j}{k} f_k=\sum_{k=0}^i f_k\sum_{j=k}^i\binom{i}{j}\binom{j}{k}(-1)^{j-k}$

$=\sum_{k=0}^if_k\binom{k}{i}\sum_{j=k}^i\binom{i-k}{j-k}(-1)^{j-k}=\sum_{k=0}^if_k\binom{k}{i}\sum_{j=0}^{i-k}\binom{i-k}{j}(-1)^j$。

而式子的后面部分是二项式定理 $x=-1$ 的特殊情况，当且仅当 $i-k=0$ 时值为 $1$ 其它时候值为 $0$，所以就可以得到 $f_i=f_i$，式子成立。

[已经没有什么好害怕的了](https://www.luogu.com.cn/problem/P4859)

考虑先排序，然后二项式反演钦定有 $1\sim n$ 个位置 $A_i>B_i$。

然后从小到大加入 $A_i$，这样子就可以计算出对于每一个 $A_i$ 当前还有几个没有配对的 $B_i$ 满足 $A_i> B_i$。

于是可以设 $F_{i,j}$ 表示考虑了前 $i$ 个 $A_i$ 已经钦定了 $j$ 对数满足 $A_i>B_i$ 此时**满足 $A_i>B_i$ 的位置**的不同配对方案数。

由于没有考虑 $A_i\le B_i$ 的随意排列的方案，所以最终答案 $F_{n,j}$ 还要乘上 $(n-j)!$。

最后通过一步二项式反演求出恰好为 $k$ 的答案。

### 单位根反演

$[x \bmod n=0]=\frac{1}{n}\sum_{i=0}^{n-1}(w^{ix}_n)$，其中 $w_n^i$ （单位根）表示 $x^n=1$ 在复数域上的 $n$ 个解分别为 $w_{n}^0(1),w_{n}^1 ,\cdots w_{n}^{n-1}$ 。

这些单位根相当于是绕着原点转一圈，每乘一个 $w_n$ 就相当于对应复数在单位圆上逆时针转了一个角度 $\frac{2\pi}{n}$， $\sum_{i=0}^{n-1}w_{n}^i=0$。

考虑当 $x \bmod n=0$ 时，$w^x=1,w^{xi}=1$ 上式显然成立。

而 $x\bmod n \neq 0$ 时每次相当于将向量旋转了 $\frac{2\pi x}{n}$ 的角度，设 $g=\gcd(x,n)$ 则转 $\frac{n}{g}$ 次就会转回原点。

每转一轮就形成一组 $g$ 个在单位圆上均匀分布的复数，它们的和为 $0$。

**在模意义下，原根也有类似的性质。**

通过单位根反演，我们可以将比较难以处理的 $\bmod$ 转化为求和的形式。

[LJJ 学二项式定理](https://loj.ac/p/6485)

将式子转化为 $\sum_{i=0}^n\binom{n}{i}s^ia_{i\bmod 4}$ 转化为 $\sum_{i=0}^n\binom{n}{i}s^i\sum_{j=0}^3a_j[(i-j) \bmod 4=0]$。

$=\frac{1}{4}\sum_{i=0}^n \binom{n}{i}s^i\sum_{j=0}^3 a_j\sum_{k=0}^3 w_4^{(i-j)k}=\frac{1}{4}\sum_{j=0}^3a_j\sum_{k=0}^3w_4^{-jk}\sum_{i=0}^n \binom{n}{i}s^i(w_4^{k})^i=\frac{1}{4}\sum_{j=0}^3 a_j\sum_{k=0}^3w_{4}^{-jk}(sw_4^k+1)^n$然后就可以通过快速幂求解了。 

对于这一题而言 $w_4^1=r^{\frac{p-1}{4}}$（$r$ 为原根）由于 $998244353=2^{23}\times 7 \times 17+1$ 所以可以找到 $\frac{p-1}{4}$。

[小猪佩奇学数学](https://www.luogu.com.cn/problem/P5591)

如果直接沿用类似上面一题的做法将 $\lfloor \frac{i}{k} \rfloor$ 变为 $\frac{1}{k}(i-i\bmod k)$，

然后 $\sum_{i=0}^n \binom{n}{i} p^ii=n\sum_{i=1}^n \binom{n-1}{i-1}p^i=np(p+1)^{n-1}$。

对于 $i\bmod k$ 部分直接沿用上一题的做法时间复杂度为 $O(k^2)$。

但是进一步分析性质 $\frac{1}{k}\sum_{j=0}^{k-1} j\sum_{p=0}^{k-1}w_{k-1}^{-jp}(sw_k^p+1)^n=\frac{1}{k}\sum_{p=0}^{k-1}(sw_k^p+1)^n\sum_{j=0}^{k-1}jw_k^{-jp}$

设 $v=w^{-p}$，则原式后面的部分可以化为 $s_{k-1}=\sum_{j=0}^{k-1}jv^j$ 

$s_k-vs_{k-1}=\sum_{j=0}^kv^j=\frac{v^{k+1}-1}{v-1}$。

也就是 $s_k=vs_{k-1}+\frac{v^{k+1}-1}{v-1}$。

继续化简可以得到 $s_k=\frac{1}{v-1}\sum_{i=0}^k(v^{i+1}-1)v^{k-i}=\frac{1}{v-1}((k+1)v^{k+1}-\sum_{i=0}^kv^i)=\frac{1}{v-1}((k+1)v^{k+1}-\frac{v^{k+1}-1}{v-1})$

$s_{k-1}=\frac{kv^{k}-\frac{v^k-1}{v-1}}{v-1}$ 而 $v^k=1$（单位根性质），也就是 $s_{k-1}=\frac{k}{v-1}$。

注意判断 $v=1$ 的情况，此时答案为 $\frac{k(k-1)}{2}$。

总时间复杂度 $O(k\log md)$。

### MinMax 容斥

$\max(S)=\sum_{T\subseteq S} (-1)^{|T|-1}\min(T)$，$S$ 中的第 $k+1$ 大元素在右边计算的次数为 $\sum_{i=0}^{k}(-1)^{i}\binom{|T|}{i}=[k==0]$，也就是第 $1$ 大的能够被统计进去。

$\max_x(S)=\sum_{T\subseteq S,|T|\ge x} (-1)^{|T|-x} \binom{|T|-1}{x-1}\min(T)$，对于 $S$ 中的第 $k$ 大元素在右边的计算次数为 $\sum_{i=x}^{k} (-1)^{i-x}\binom{k-1}{i-1}\binom{i-1}{k-1}=\binom{k-1}{x-1}\times_{i=x}^k (-1)^{i-k}\binom{k-x}{i-x}=[k==x-1]$

上面的式子将 $\text{lcm}$ 和 $\gcd$ 代入,依然成立，可以对 $\text{lcm}$ 和 $\gcd$ 进行转化。

此外 MinMax 容斥常常用于将“全部”转为“至少”，特别是在一些期望问题上有很大的应用，因为期望的线性性，所以 MinMax 容斥仍然成立。往往“至少一个”的期望时间是容易计算的，但是全部满足的期望时间就不容易计算。



[重返现世](https://www.luogu.com.cn/problem/P4707)

相当于询问全集中第 $x$ 个出现的元素的期望出现时间，也就是出现时间第 $n-x+1$ 大的元素的期望出现时间。应用上面 $max_x(S)$ 的结论转化为在子集 $T$ 中出现第一个元素的期望时间计算，发现最小值的期望为 $\frac{m}{\sum_{j\in T}a_j}$，也就是只和 $T$ 中  $a_j$ 的和有关，我们可以通过背包求出当 $\sum_{j\in T}a_j=i,|T|=k$ 时的 $T$ 数量，然后计算，但是背包直接计算是 $O(nxm)$ 的。

考虑其实 $n-x+1$ 很小，需要从这里入手，发现主要是 $(-1)^{|T|-(n-x+1)}\binom{|T|-1}{i-1}$ 非常阴间，尝试将 $(-1)^{|T|-(n-x+1)}\binom{|T|-1}{i-1}$ 计入 DP 来避免直接记录 $|T|$。

设 $F_{i,j,k}=P_{i,j,k}$ 否则 $F_{i,j,k}= \sum_{T\subseteq\{a_1,a_2,\cdots,a_i\},\sum_{v\in T}=j}(-1)^{|T|-k}\binom{|T|-1}{k-1}$，我们要求的就是 $F_{i,j,n-x+1}$

设计转移时会发现很微妙的一点是 $(-1)^{|T|-k}\binom{|T|-1}{k-1}=-(-1)^{|T|-k-1}\binom{|T|-2}{k-1}+(-1)^{|T|-k}\binom{|T|-2}{k-2}$，于是 $F_{i,j,k}=F_{i-1,j,k}+(F_{i-1,j-a_i,k-1}-F_{i-1,j-a_i,k})$，后面这一部分就应用到了这个公式。

然后 $k$ 这一维就只用记录 $n-x+1$ 了！这启示我们当直接 DP 优化受阻的时候我们也许试着可以将 DP 数组记录的东西和 DP 值里的东西进行一些互换。
